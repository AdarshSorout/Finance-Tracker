# FedEx Shipment Tracking Web App

A full-stack FedEx-style shipment tracking application built using **Django** (backend) and **ReactJS** (frontend).

## 🚀 Features
- Track shipments by FedEx tracking number
- RESTful API built using Django REST Framework
- SQLite database for storage
- ReactJS frontend for real-time updates

## 🛠️ Tech Stack
- Django
- Django REST Framework
- ReactJS
- SQLite
- Environment Variables (.env)

## 💻 Run Locally
```bash
cd Backend/fedextrackdjango
python manage.py runserver
